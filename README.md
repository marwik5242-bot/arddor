# 13ag Menu Studio 0.2.0 (Fabric 1.21.4)

Сборка (нужны JDK 21 и Gradle 8.12+):

    gradle build

Готовый JAR: build/libs/13ag-menu-studio-0.2.0.jar  (файл *-sources.jar не нужен)
Положить в .minecraft/mods вместе с Fabric API (0.119.x для 1.21.4).

Без установки Java/Gradle: залить проект на GitHub, вкладка Actions -> build -> Artifacts.

Конфиг: config/13ag-menu-studio.json (старый файл 0.1.x читается).
Редактор: кнопка "13ag" в левом верхнем углу главного меню или клавиша F8 в игре.
